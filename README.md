# 📚 Подробное Руководство Разработчика (Developer Guide)

Добро пожаловать в проект **«Міністерство Запчастин»**! Этот документ — ваш главный путеводитель по архитектуре, коду и бизнес-логике приложения по подбору автозапчастей. Он написан так, чтобы даже начинающий разработчик смог разобраться в том, как всё устроено.

---

## 🛠 1. Используемые Технологии (Стек)

Приложение разделено на две независимые части: **Frontend** (браузер) и **Backend** (сервер).

### Frontend (Клиентская и Админская части)
Без тяжёлых фреймворков (React, Angular). Всё на базовых технологиях:
* **HTML5** — разметка и структура интерфейса.
* **CSS3** — стили, цвета (Royal Blue UI Theme `#2563eb`), анимации, адаптивная вёрстка (flexbox/grid).
* **Vanilla JavaScript (JS)** — логика: нажатия кнопок, отправка данных на сервер, навигация по вкладкам, чат и оформление заказов.

### Backend (Серверная часть)
* **Python 3** — основной язык программирования.
* **FastAPI** — современный веб-фреймворк для создания REST API с автогенерацией документации (Swagger).
* **SQLAlchemy** — ORM (Object-Relational Mapping). Работаем с базой данных через объекты Python вместо сырых SQL-запросов.
* **Pydantic** — библиотека строгой валидации данных. Встроена в FastAPI.
* **PostgreSQL** — основная база данных (используется на Render в продакшене).
* **passlib + bcrypt** — криптографическое хеширование паролей.

### Деплой и Хостинг
* **Render.com** — облачный хостинг для бекенда (автоматический деплой при каждом `git push` в `main`).
* **GitHub Pages / Static Hosting** — раздача фронтенда.

## 🗄 3. База Данных (models.py)

В файле `backend/app/models.py` описана структура всех таблиц. SQLAlchemy автоматически переводит классы Python в таблицы PostgreSQL.

### Главные Таблицы:

| Таблица | Назначение | Ключевые поля |
|---------|-----------|---------------|
| **Client** | Учётная запись клиента | `phone`, `email`, `hashed_password`, `auth_token`, `is_verified` |
| **Car** | Автомобиль в гараже клиента | `vin`, `brand`, `model`, `generation`, `body_type`, `engine_code`, `mileage`, `owner_id` |
| **OrderRequest** | Запрос на подбор запчастей | `client_id`, `car_id`, `category`, `description`, `status` |
| **Proposal** | Смета (ответ менеджера) | `request_id`, `manager_comment`, `status` |
| **ProposalItem** | Позиция в смете | `proposal_id`, `name`, `category_name`, `oem_number` |
| **ProposalAlternative** | Вариант по позиции (аналог) | `item_id`, `brand`, `part_number`, `price`, `is_selected` |
| **Order** | Оформленный заказ | `status`, `ttn_number`, `total_price`, `purchase_cost` |
| **OrderItem** | Позиция в заказе | `order_id`, `alternative_id`, `quantity` |
| **ChatMessage** | Сообщение в чате | `request_id`, `message`, `sender_type`, `attachment_url` |

## 🔍 4. Декодер VIN и Определение Поколения (vin_decoder.py)

Модуль `backend/app/routers/vin_decoder.py` использует двухэтапную систему расшифровки:

1. **NHTSA vPIC API (США)**:
   - Извлекает марку (`Make`), модель (`Model`), год (`ModelYear`), тип кузова (`BodyClass`), объем двигателя (`DisplacementL`), число цилиндров, мощность (`EngineHP`), тип привода (`DriveType`), тип трансмиссии (`TransmissionStyle`) и город/страну завода.
2. **Интеллектуальный Сопоставитель Поколений (`infer_generation`)**:
   - Преобразует года и модель в точный код кузова/поколения:
     - **BMW**: `5 Series` 2019 → `G30 / G31`, `3 Series` 2016 → `F30 / F31 / F34`.
     - **Audi**: `A4` 2017 → `B9 (8W)`, `A6` 2013 → `C7 (4G)`.
     - **Mercedes-Benz**: `C-Class` 2018 → `W205`, `E-Class` 2017 → `W213`.
     - **Volkswagen / Skoda / Toyota / Honda / Ford / Hyundai / Kia**: автоматические правила поколений.
   - **Распознавание европейских VIN**: считывание кодов кузова прямо из позиции 4–8 VIN (`8K` у Audi → `B8 (8K)`, `205` у Mercedes → `W205`, `3C` у VW → `Passat B6/B7`).

## 💬 5. Чат и Интерактивная Смета (Proposal in Chat)

Главным каналом связи между клиентом и менеджером является **Чат** (вкладка 3 в нижнем меню):

1. **Выбор темы/запита**: Клиент может переключаться между своими запитами через выпадающий список вверху чата.
2. **Живой диалог**: Клиент и менеджер обмениваются текстовыми сообщениями и фотографиями запчастей/техпаспорта.
3. **Интерактивная Смета (`Proposal`) в чате**:
   - Когда менеджер формирует предложение, в ленте сообщений появляется блок **`📋 Кошторис від Експерта`**.
   - Клиент прямо в чате выбирает варианты запчастей (оригинал / аналог), указывает адрес доставки Новой Почтой и способ оплаты, после чего нажимает **`🛒 Оформити замовлення з кошторису`**.

## 📱 6. Навигация Клиента (6 Вкладок)

Нижнее меню клиентского приложения содержит 6 разделов:

1. **🚗 Гараж** (`garage`) — список автомобилей клиента с паспортом авто, пробегом и PIN-кодом для продажи.
2. **🛠️ Підбір** (`requests`) — упрощенная форма заказа для пожилых людей («для деда»):
   - **🛢️ Швидке ТО & Всі Рідини** (масло, фильтры, антифриз).
   - **🛑 Гальма (Перед / Зад)** (диски, колодки).
   - **✏️ Інше (напишіть словами)** — простое текстовое поле.
   - **Облака вузлів** (Двигатель, Тормоза, Ходовая, КПП, Электрика, Охлаждение) с кликабельным выбором через sub-catalog modal.
3. **💬 Чат** (`chat`) — развернутый диалог с экспертом и сметами.
4. **📋 Підбори** (`my_requests`) — история всех отправленных запросов.
5. **📦 Замовлення** (`orders`) — текущие заказы, статусы сборки и ТТН Новой Почты.
6. **👤 Профіль** (`profile`) — личные данные клиента, адрес доставки.

## 🛡 7. Безопасность и Валидация

* **Хеширование паролей:** bcrypt + passlib.
* **Токены:** `X-Auth-Token` хранится в `localStorage` и передается с каждым запросом.
* **OTP-подтверждение:** восстановление пароля по Email.

## 🚀 8. Деплой на Render

При каждом `git push` в ветку `main` Render автоматические собирает и перезапускает бекенд:

```bash
uvicorn backend.app.main:app --host 0.0.0.0 --port $PORT
```

Версии скриптов фронтенда инкрементируются (`?v=39.0`) для сброса кеша браузера.
